## Color variations

Each of the four lockups above ships in six color treatments:

| Variant | Background it's designed for |
|---|---|
| Solid Blue | Light backgrounds (the default, shown above) |
| Solid Black | Light backgrounds |
| All White / Reversed | Dark backgrounds |
| Dark Blue / White | Dark backgrounds |
| White / Gold | Dark backgrounds |
| White / Black | Mid-tone gray backgrounds |

See the [source PDF](/brand/Tahche-Brand-Guidelines.pdf) for every lockup × color combination —
this page documents the usage rules, not all 24 raster/vector exports.

## Logo color on different backgrounds

- **Light background** — use the primary (Solid Blue) version. The background must be
  sufficiently light (pure white or light gray tints) that every element of the mark stays
  legible. Never use a light or white treatment of the logo on a light background — it will
  blend in.
- **Dark background** — use an inverted treatment (All White/Reversed, Dark Blue/White, or
  White/Gold) so the mark keeps maximum contrast. Never place the standard full-color (Solid
  Blue/Black) logo directly on a black or dark background without a container or backing.
- **Gray background** — on a light gray background, use the standard full-color logo; on a dark
  gray background, use an inverted white treatment. If contrast between the gray and the logo is
  still insufficient, add a brand-colored container (backing) behind it rather than forcing it.

## Clear space

Always maintain a margin of empty space around the logo on every side — no text, graphic
elements, or layout boundaries (rules, dividers, container edges) may sit inside that margin. The
Brand Guidelines illustrate this proportionally (see diagram above) rather than specifying an
exact measurement, unlike the minimum-size rule below.

## Minimum size

<img src="/brand/logo-minimum-size.png" alt="Logo minimum size diagram" class="mx-auto my-6 max-w-md rounded-md border border-neutral-200" />

Never render the full lockup smaller than **30px / 4.5mm in height**.

## Unacceptable use

<img src="/brand/logo-unacceptable-use.png" alt="Unacceptable logo use examples" class="mx-auto my-6 max-w-2xl rounded-md border border-neutral-200" />

- **Never** distort the logo (stretched or squashed proportions).
- **Never** leave strokes/outlines unapplied — the mark must render as solid fills, not an
  outline.
- **Never** apply shadows, gradients, or glows.
- **Never** rotate or tilt the logo.
- **Never** place it on a background that hinders readability (busy photos, low-contrast
  surfaces).
- **Never** use a low-quality, blurry, or compressed export.

## Favicon

<img src="/brand/favicon-variants.png" alt="Favicon variants — full silhouette, cheetah head, and T monogram" class="mx-auto my-6 max-w-2xl rounded-md border border-neutral-200" />

Three forms, in order of preference:

1. **Full cheetah silhouette** (16×16 / 32×32) — favicons, small packaging labels, apparel
   embroidery. Default baseline for small-to-medium formats needing the full figure.
2. **Cheetah head** (16×16 / 32×32) — merchandise, sticker packs, apparel prints, social media
   avatars/templates. A complementary asset for diversifying touchpoints, not a replacement for
   the silhouette.
3. **Letter "T" monogram** (16×16 / 32×32) — micro-printing, hardware embossing (buttons,
   rivets), single-color applications (engraving, stamps). Use only when a technical limitation
   would render the cheetah unreadable at that scale.

## App icon

<img src="/brand/app-icon-color-variants.png" alt="App icon color variants" class="mx-auto my-6 max-w-2xl rounded-md border border-neutral-200" />

The small-scale app icon is a 400×400 rounded-square export of the mark-only lockup, available in
the color/background combinations shown above.

<img src="/brand/app-icon-minimum-size.png" alt="App icon minimum size" class="mx-auto my-6 max-w-md rounded-md border border-neutral-200" />

Never render the app icon smaller than **32px / 6mm**.
