# Logo

## Lockups

<img src="/brand/logo-lockups-05.png" alt="Tahche vertical and horizontal logo lockups" class="mx-auto my-6 max-w-2xl rounded-md border border-neutral-200" />

- **Vertical (main)** — for general use across digital and print materials and brand collaterals.
- **Horizontal** — a variation with the same use as the main logo, for layouts that need a wide
  rather than tall lockup.

## Color variations

Both lockups ship in three treatments: full color (on light backgrounds), all-white (on the
brand's Royal Blue), and all–Royal Blue (on the brand's Yellow). See the source
[Brand Book PDF](/brand/Tahche-Brandbook.pdf) for the exact assets — this site documents the
usage rules, not the raster/vector exports themselves.

## Clear space and minimum size

- All sides of the logo placement must have a clear-space margin of **15mm**.
- The signature should never be used smaller than **40mm** width.

## Incorrect usage

- **Never** place the signature on a complex (busy photographic) background.
- **Never** reproduce it with an outer glow — a slight drop shadow is acceptable instead.

## When to use which lockup

- Default to the **Vertical** lockup unless the layout is meaningfully wider than it is tall (a
  banner, an email header, a horizontal nav bar) — use **Horizontal** there instead.
- This is a marketing/document asset — see [Brand vs. Product](/brand/brand-vs-product) for why
  the product UI itself doesn't use these logo lockups as a design token.
